# architecture-propdevelopment

Проектная работа 5-го спринта: подготовка PropDevelopment к комплексному аудиту безопасности.

| Директория | Задание | Файлы |
|---|---|---|
| `Task1` | Проверочный лист по безопасности данных (mindmap) | `data-security-mindmap.drawio` — классификация данных по ISO/IEC 27001/27002, риски и их оценка |
| `Task2` | Проверочный лист для бизнес-систем | `security-checklist.md` — системы, выбор разделов с обоснованием, заполненный чек-лист |
| `Task3` | Внешние интеграции «Умный дом» | `c4-context-smart-home.drawio`, `c4-containers-updated.drawio`, `integration-requirements.md` |
| `Task4` | RBAC в Kubernetes | `roles.md` (таблица ролей), `01-create-users.sh`, `02-create-roles.sh`, `03-bind-roles.sh` |
| `Task5` | Сетевые политики Kubernetes | `non-admin-api-allow.yaml`, `deploy-and-test.sh`, `README.md` |

Файлы `.drawio` открываются в [draw.io](https://app.diagrams.net) или в расширении draw.io для VS Code.
